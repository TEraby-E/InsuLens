# Model cards

Model binaries are ignored by normal Git rules. If they are published, use the
repository's Git LFS configuration and keep the checksum and data provenance in
this file.

point for real-domain transfer learning.

| Training data | 500 automatically annotated Gazebo images |
| Training | 30 epochs, 640 px input, trained from `yolov10s.yaml` |

## `insulator_defect_yolov10s.pt`

Real-scene checkpoint initialized from `insulator_yolov10s.pt`, with the
detection head expanded to two classes and fine-tuned on CPLID.

| Field | Value |
|---|---|
| Architecture | YOLOv10s |
| Classes | `insulator`, `missing_disc` |
| Training data | CPLID: 678 train / 170 validation images |
| Validation instances | 269 `insulator`, 50 `missing_disc` |
| Training | 50 epochs, 768 px input, batch 8 |
| All classes | P 0.791, R 0.844, mAP50 0.882, mAP50-95 0.530 |
| `insulator` | P 0.668, R 0.729, mAP50 0.785, mAP50-95 0.484 |
| `missing_disc` | P 0.914, R 0.960, mAP50 0.980, mAP50-95 0.575 |
| Size | 16,530,171 bytes |
| SHA-256 | `a61f1bea6896f721a23c0697258eab66d3be60aaca998e1477895fe6d8c273f6` |

Metrics are from the fixed-seed CPLID split generated by
`scripts/prepare_cplid.py`; they are not an independent field-site benchmark.
CPLID contains real UAV normal-insulator images, while its defective images use
synthesized defective insulators placed onto transmission-scene backgrounds.
The upstream dataset has no explicit license declaration, so use it for
research/coursework with attribution and do not redistribute its images.

Dataset citation:

> X. Tao et al., "Detection of Power Line Insulator Defects Using Aerial Images
> Analyzed With Convolutional Neural Networks," IEEE Transactions on Systems,
> Man, and Cybernetics: Systems, 2018.
